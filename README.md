# Project Tracker

A project management application built with React.js to practice component-based development, state management, and interactive user interfaces.

## Live Demo

[View Project Tracker](https://project-tracker-app-iota.vercel.app/)

## About The Project

Project Tracker is a simple application that helps users organize and manage their projects in one place.

It provides an interactive interface for adding projects, updating their progress, and filtering them based on their completion status.

## Features

- Add new projects.
- Delete existing projects.
- Update project status.
- Filter projects by status.
- Dynamically update the interface using React state.
- Responsive user interface.

## Technologies Used

- React.js
- JavaScript (ES6+)
- CSS3
- Vite

## Getting Started

To run the project locally:

1. Clone the repository:

   git clone https://github.com/Nour159535/Project-Tracker

2. Navigate to the project directory:

   cd project-tracker

3. Install dependencies:

   npm install

4. Start the development server:

   npm run dev
